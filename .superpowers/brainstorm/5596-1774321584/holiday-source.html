How should the card know what's coming next?

The Jewish Calendar integration only reports today's holiday. It has no "upcoming holiday" sensor. We need another source.

A

Built-in Hebrew calendar lookup

Embed a holiday table in the card code — map Hebrew dates to holidays. We already have the Hebrew date sensor (currently "6 Nisan 5786"). The card computes days until the next holiday from the Hebrew date. No extra dependencies, works offline, but we maintain the table ourselves.

B

Detect from candle lighting divergence

The integration has both upcoming_candle_lighting and upcoming_shabbat_candle_lighting. When these differ, a Yom Tov is coming before Shabbat. Clever but limited — only works for Yom Tov with issur melacha, not minor holidays or fasts. And doesn't tell us which holiday.

C

Use the HA calendar entity

If the Jewish Calendar integration exposes a calendar entity, we could query upcoming events from it. Clean API approach, but requires checking if this entity exists and what data it provides.
