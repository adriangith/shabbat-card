Which holidays should the card track?

The Jewish Calendar integration knows about 38 different occasions. Which matter to you?

A

Major Yom Tov Only

Pesach, Shavuot, Sukkot, Shmini Atzeret/Simchat Torah, Rosh Hashana, Yom Kippur — the days with issur melacha. These are the ones that behave like Shabbat.

B

+ Minor / Rabbinic Holidays

Add Chanukah, Purim, Tu B'Shvat, Lag B'Omer, Tu B'Av — festive days without melacha restrictions. These wouldn't change the candle/progress behavior but could show upcoming info.

C

+ Fast Days

Add Tzom Gedaliah, Asara B'Tevet, Ta'anit Esther, Tish'a B'Av, Tzom Tammuz — these have a very different character (somber, no festive greeting).

D

+ Chol HaMoed & Erev

Add the intermediate days of Pesach/Sukkot and preparation days (Erev Pesach, Erev Rosh Hashana, etc.) — contextual but not holy days themselves.
